# PungrangLauncher 개발 로드맵

풍랑빌 공식 런처의 목표는 Minecraft Java Edition 1.21.1 / NeoForge 21.1.265 환경을 사용자가 직접 구성하지 않아도 설치·업데이트·실행할 수 있게 하는 것입니다.

## 개발 우선순위

| 순서 | 기능 | 완료 기준 |
|---:|---|---|
| 1 | Microsoft 계정 로그인 | Microsoft 로그인, Xbox Live/XSTS 인증, Minecraft 프로필 및 보유 권한 확인, 안전한 토큰 캐시와 로그아웃 |
| 2 | Minecraft 및 NeoForge 자동 설치 | Java 런타임 확인/설치, Minecraft 1.21.1 설치, NeoForge 21.1.265 프로파일 설치 및 무결성 검증 |
| 3 | 게임 실행 및 메모리 설정 연결 | 선택한 계정과 설치 프로파일로 실행, 최소/최대 메모리 설정 적용, 실행 상태 및 종료 감지 |
| 4 | 모드팩 자동 업데이트 | 원격 manifest 버전 비교, SHA-256/파일 크기 검증, 변경 파일만 다운로드, 사용자 월드와 개인 설정 보존 |
| 5 | Velopack 런처 자동 업데이트 | 업데이트 채널, 새 버전 확인, 설치/복구, 실패 시 안전한 롤백 |
| 6 | 정식 Windows 설치 EXE | 설치/제거, 바로가기, 설치 경로 및 업데이트 연동, 서명 및 배포 검증 |

## 구현 원칙

- 대상 게임 버전은 Minecraft Java 1.21.1, NeoForge 21.1.265, Windows x64입니다.
- Microsoft 계정 비밀번호를 런처가 직접 수집하지 않습니다. Microsoft가 제공하는 브라우저 기반 인증을 사용합니다.
- OAuth client secret, 사용자 토큰, 개인 키는 저장소에 커밋하지 않습니다.
- 인증 토큰은 Windows 사용자 범위의 안전한 저장소를 사용하고 로그에 출력하지 않습니다.
- 게임 파일은 공식 manifest/다운로드 메타데이터를 기준으로 설치하고 해시를 검증합니다.
- 모드팩 업데이트는 사용자 월드와 개인 설정을 기본적으로 보존합니다.
- 모드 파일은 배포 권한과 라이선스가 확인된 파일만 manifest에 등록합니다.
- 런처 자체 업데이트와 Windows 설치 프로그램은 게임 설치/실행 기능이 검증된 뒤 적용합니다.

## 현재 상태

현재 저장소에는 WPF 런처 기본 화면, 공지사항 조회, Minecraft 서버 상태 조회가 있습니다. 위 6개 항목은 아직 개발·검증이 필요한 단계이며, 체크리스트는 실제 구현과 테스트가 완료된 뒤에만 완료로 변경합니다.

## 릴리스 정책

- 초기 개발 빌드는 GitHub Actions 아티팩트로 검증합니다.
- v0.1.0 등의 정식 Release 태그는 해당 버전의 기능과 테스트 범위가 명확해진 뒤 생성합니다.
- 정식 Windows 설치 EXE는 6번 항목에서 Velopack 기반 설치/업데이트 구성을 확정한 뒤 배포합니다.
